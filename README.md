# API Tracker — Zdravko App

A simple web application for tracking APIs.

## Features

- Add and view API records
- REST API backend
- Database storage
- Built with Flask

## Technologies

- Python
- Flask
- SQL database
- Git / GitHub

## How to Run

1. Clone the project:

```bash
git clone [https://github.com/abesic1/API-Tracker----Zdravko-App.git](https://github.com/abesic1/API-Tracker----Zdravko-App.git)
cd API-Tracker----Zdravko-App
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start the app:

```bash
python app.py
```

4. Open in your browser:

```text
http://127.0.0.1:5000
```
